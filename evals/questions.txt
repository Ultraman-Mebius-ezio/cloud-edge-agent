# 对照实验题集（direct vs dot 跑同一批）
#
# 格式：一行一题；`#` 开头是注释；空行忽略。
# 选取原则：覆盖 allocator 的两条分支，否则两种模式的差异测不出来——
# 全是简单题则 dot 没什么可下沉的，全是难题则 direct 和 dot 都上云。
#
# 每条后面的 [预期] 只是**人工标注的直觉判断**，不是标准答案，
# 用来事后核对 allocator 的规则是否符合预期，不要拿它当评分依据。

# —— A 组：预期整条走本地（短、纯算术/单点事实） ——
37 乘以 48 等于多少？                                        # [预期] 纯算术 → local
一箱苹果 24 个，吃掉 7 个还剩几个？                            # [预期] 纯算术 → local
156 除以 12 等于多少？                                       # [预期] 纯算术 → local

# —— B 组：预期整条走云端（开放、需要权衡） ——
请解释端云协同架构的主要优势和潜在风险，并比较它与纯云端方案的差异。  # [预期] 开放 → cloud
为什么在移动端部署大模型时，量化通常比蒸馏更划算？请分析原因。          # [预期] 开放 → cloud

# —— C 组：多步题（dot 的分解才有意义的场景） ——
一个班有 45 名学生，其中 3/5 是女生。女生比男生多几人？        # [预期] 分解后含纯算术子任务 → 混合
小明每天跑步 3 公里，一周跑 5 天，连续跑 4 周，总共跑了多少公里？ # [预期] 分解后含纯算术子任务 → 混合
一件商品原价 320 元，先打八折再减 20 元，最终价格是多少？      # [预期] 分解后含纯算术子任务 → 混合

# —— D 组：长上下文/依赖题（压 runner 的前置答案预算） ——
先算出 18 的平方是多少，再用这个结果减去 100，最后说明这个差值正负号的物理含义。
